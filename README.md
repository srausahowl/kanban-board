# Kanban Board

Drag-and-drop task board with multiple columns, tags, and add/delete cards. Built with the native HTML drag-and-drop API.

## Live Demo

https://srausahowl.github.io/kanban-board/

## Usage

Open `index.html` in any modern browser. Zero dependencies, zero build step.

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Tech

- Vanilla HTML / CSS / JavaScript
- No frameworks, no build tools
